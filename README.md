# tv-guia-br

Guia de programacao (XMLTV) para a lista de canais do Brasil do [iptv-org](https://github.com/iptv-org/iptv), regerado todo dia pelo GitHub Actions com o grabber do [iptv-org/epg](https://github.com/iptv-org/epg).

- Guia: `https://marcelinollima.github.io/tv-guia-br/guia.xml.gz`
- Lista: `https://iptv-org.github.io/iptv/countries/br.m3u`

So' entram os canais da lista que tem programacao em algum site suportado pelo iptv-org/epg (cerca de 170 de 396).
